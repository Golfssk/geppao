# Geppao category mockup illustrations

Six original SVG illustrations created for the Geppao search-card design: accommodation, restaurant, cafe, attraction, activity and event. One file is reused per category.

These are generic concept illustrations, **not photographs or depictions of the named businesses, locations or events**. They do not establish amenities, scenery, room appearance, safety or availability. No third-party photos, logos, fonts, reviews or remote assets are embedded.

Only use as a fallback when an approved real image is absent. Keep the visible TH/EN mockup notice and generic image alternative text. Existing approved venue images take precedence. Do not store these as a venue's cover image or mark them owner-verified.
