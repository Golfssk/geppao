# Phase 19 — Pilot Runbook

## Pilot groups

Run at least one complete journey for each group:

- Family
- Couple
- Friends
- Pet-friendly traveler
- Budget traveler
- Business owner
- Admin/Curator

## Traveler scenario

1. Search for a real published Place.
2. Open its detail page.
3. Run Planner with dates, traveler count, and budget.
4. Save the result as a Trip.
5. Add and remove one item.
6. Lock one item.
7. Recalculate the Trip.
8. Open Google Maps navigation.
9. Share the read-only Trip.
10. Confirm the shared Trip exposes no owner ID and no unpublished Place/Event.

## Admin scenario

1. Open `/admin/analytics`.
2. Confirm the test journey appears in event counts.
3. Confirm Planner → Trip conversion is calculable.
4. Confirm Place engagement appears only for published Places.
5. Confirm a non-Admin cannot open the dashboard or read analytics rows.

## Evidence to record

- Pilot role and date.
- Whether a Trip was created.
- Whether navigation was opened.
- Whether the Trip was shared.
- Added/removed recommendations.
- Schedule warning/conflict count.
- Missing-data blockers.
- Incident IDs.
- Feedback and optimization candidate.

## Completion rule

Implementation and a working dashboard make Phase 19 launch-ready. Phase 19 is Completed only after real pilot evidence has been reviewed and critical incidents have been resolved or accepted.
