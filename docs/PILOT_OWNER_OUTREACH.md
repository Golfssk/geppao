## Outreach message

อยากเชิญ [ชื่อธุรกิจ] ทดลองใช้เวลา 20–30 นาที เพื่อดูว่า:
- นำเข้าข้อมูลจากเว็บไซต์/Facebook ได้เร็วหรือไม่
- เวลา ราคา พิกัด และช่องทางติดต่อแก้ไขง่ายหรือไม่
- การส่งรูปและยืนยันสิทธิ์ชัดเจนหรือไม่
- จุดใดทำให้เสียเวลาหรือต้องให้ทีมช่วย

รอบ Pilot ไม่มีค่าใช้จ่าย และเราจะไม่จัดอันดับแบบชำระเงินแฝง หากสนใจ กรุณาตอบกลับพร้อมผู้ประสานงานและเวลาที่สะดวก

## Success metrics

- invitation → reply
- reply → scheduled session
- scheduled → signup

- Business created → first Draft
- Draft → submitted for review
- time to first Draft
- number of support interventions
- record fields corrected by owner
- image permission completed
